Deepwarren

A free online co-op Android demo inside an immense, changing fungal underworld.

Download the Android APK · Windows setup · Mac setup (experimental)

Android & Thor

Install the APK and open the game. It connects automatically to our server. No GPU, model download, VPN or server configuration is needed on your device.

Play on Windows or Mac

Our experimental guided setup downloads Google's Android emulator tools, installs the game and opens its two displays. Android Studio and a development project are not required. The Windows setup targets Intel/AMD x64; the Mac setup selects an Apple Silicon or Intel image.

A fresh Windows setup and physical Mac installation have not yet been fully verified. The launchers respect normal OS security: if Windows script policy or macOS verification blocks setup, stop and report the message; do not disable those protections. Check Google's computer requirements.

A shared online world

Up to eight players share one living world at the same time. Internet access is required. When all player slots are occupied, the game shows your queue position and admits you when a space opens. Hosting is provided by the developer's PC; availability may vary.
